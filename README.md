# AJT Accounting Static Site

Static rebuild of `ajt-accounting.com` for GitHub Pages.

## Preview locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Launch notes

- DNS is not managed from this repository.
- Contact form behavior needs a final decision before launch. The current static preview uses email and phone links instead of a WordPress form backend.
- Privacy Policy and Terms pages were migrated from the live site with current sitewide contact info; review before public launch.
